# Serotonin 바로캡처 (v1.0.0)

제작 이은호 · 문의 serotonin.1207@gmail.com · 광고·계정·서버 없이 PC 안에서만 동작하는 Windows 화면 캡처 도구입니다.
단축키를 누르고 영역을 선택하면 이미지를 저장하면서 클립보드에도 복사합니다. HWP·워드 등에서 `Ctrl+V`로 바로 붙여넣을 수 있습니다.

캡처 직후에는 화면 우하단에 **미리보기 카드**(CleanShot 스타일)가 떠서 편집·고정·저장·텍스트 추출을 바로 고를 수 있고,
잠시 두면 스스로 사라집니다. (일반 설정에서 예전처럼 편집 창이 바로 열리게 바꿀 수 있습니다.)

캡처 방식은 세 가지입니다 — **영역 캡처**(드래그), **창 캡처**(마우스 아래 창 자동 인식, 클릭 한 번),
**스텝 캡처**(클릭할 때마다 자동 캡처 + 번호 배지 → 완료 시 단계별 매뉴얼 이미지 자동 생성).
**화면 고정(Pin)** 으로 캡처를 항상-위 창으로 붙여두고 참고하며 작업할 수 있습니다 (드래그 이동 · 휠 크기조절 · 더블클릭 닫기).

UI는 크림빛 배경 + 흰 카드 + 맥 시스템 블루 액센트의 CleanShot 풍 디자인이며, 설정은 토글 스위치로 켜고 끕니다.

## 환경설정 구성
- **일반 설정**: 오버레이, 자동 시작, 클립보드 복사, 저장 알림, 가이드라인 색
- **고급 설정**: 저장 폴더(기본 `다운로드\캡처`), 파일명 형식, 자동저장, JPG/PNG/BMP/GIF/WEBP, 품질, 크기 프리셋
- **단축키 설정**: 전역 영역 캡처 단축키(기본 `Ctrl+Shift+Z`)와 Print Screen 설정
- **캡처목록 설정**: 최근 목록의 알림·자동 정리 정책

편집 창은 CleanShot식 구성입니다 — 상단 슬림 바(새 캡처·되돌리기·회전 / 텍스트 추출·꾸미기·복사·저장·완료), 왼쪽 세로 도구 레일(선택·텍스트·번호·스탬프·펜·형광펜·도형·모자이크·자르기·삭제, 현재 도구는 파란 하이라이트), 하단 내보내기 바(형식·크기·여백·용량). 아이콘은 Pillow로 그린 벡터풍 이미지이며, `소스코드/icons/{이름}.png` 파일을 두면 직접 그린 아이콘으로 교체됩니다 (이름: select, text, number, stamp, pen, highlight, shape, mosaic, crop, delete, home, image, folder, undo, redo, rotate, reset, ocr, sparkle).
도구: 텍스트·번호·스탬프(✓ ✗ ★ 등)·도형·펜·형광펜(반투명)·자(직선)·모자이크(픽셀/부드러운 흐림)·자르기. 텍스트는 더블클릭으로 편집합니다. `Ctrl+Z`(이전)/`Ctrl+Y`(다시)/`Ctrl+S`(저장)/`Ctrl+C`(클립보드 복사)/`Esc`(도구 취소) 단축키를 지원합니다.
하단의 **용량 맞추기**로 저장 파일을 목표 용량(300KB~2MB 프리셋 또는 직접 입력) 이하로 자동 조정할 수 있습니다 — JPG/WEBP는 품질을 먼저 낮추고, 그래도 크면 이미지 크기를 줄입니다.

- **✨ 꾸미기**: 캡처에 둥근 모서리 + 그림자 + 그라데이션 배경을 입혀 발표자료용으로 만듭니다 (퍼플 블루·민트·선셋·그레이·화이트).
- **🔤 텍스트 추출(OCR)**: Windows 내장 OCR로 이미지 속 글자를 뽑아 클립보드에 복사합니다. 인터넷 연결 없이 동작하며 `winsdk` 패키지와 Windows 한국어 언어 팩이 필요합니다.
- **🛡 개인정보 가리기**: OCR로 전화번호·이메일·주민등록번호·카드번호 형태를 찾아 클릭 한 번에 자동 모자이크합니다.
- **💬 콜아웃**: 말풍선(설명 상자, 꼬리가 대상을 가리킴)과 돋보기 확대(특정 부분을 2배 원으로 강조)를 제공합니다.

## 소스 구성 (모듈)
| 파일 | 역할 |
|---|---|
| `config.py` | 상수·설정 load/save·자동시작·단일 실행·단축키 파싱 |
| `assets.py` | 트레이 아이콘·DPI 설정 |
| `ui.py` | CleanShot 풍 디자인 시스템 (팔레트·토글 스위치·알약 버튼) |
| `hotkey.py` | 전역 단축키 리스너 |
| `selector.py` | 영역 선택 창 (다중 모니터 지원) |
| `windowpick.py` | 창 캡처 (마우스 아래 창 자동 인식) |
| `stepcap.py` | 스텝 캡처 (클릭마다 자동 캡처 → 매뉴얼 생성) |
| `pin.py` | 화면 고정(항상-위 플로팅 이미지) |
| `thumbbar.py` | 캡처 직후 우하단 플로팅 미리보기 카드 |
| `ocr.py` | Windows 내장 OCR 텍스트 추출 |
| `editor.py` | 편집 창 |
| `app.py` | 설정창·캡처 흐름·트레이 |
| `hwp_capture.py` | 진입점(main) |

## 실행 (소스에서)
```powershell
python -m pip install -r requirements.txt
python hwp_capture.py
```

## 설치 파일 만들기
```powershell
# 1) 독립 실행 EXE 빌드 (OCR 기능 포함 시 --collect-all winsdk 필요)
python -m pip install pyinstaller pystray winsdk
pyinstaller BaroCapture.spec

# 2) 설치 파일(setup) 생성 — Inno Setup 6 필요
ISCC.exe installer.iss
```
완성 설치 파일은 `Output\Serotonin_BaroCapture_Setup_v1.0.0.exe`입니다.
