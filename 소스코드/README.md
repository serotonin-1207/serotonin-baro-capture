# Serotonin 바로캡처 v3.0.7

영역을 캡처하고 최근 이미지를 다시 복사하는 Windows 도구입니다.

- **Ctrl+Shift+Z**: 영역을 드래그하면 즉시 클립보드에 복사합니다. 캡처 중 취소는 Esc입니다.
- **최근 캡처**는 트레이 아이콘을 클릭해 엽니다. 이미지를 고른 뒤 더블클릭, Enter 또는 다시 복사를 누릅니다. 선택한 이미지 하나를 지우려면 **삭제**, 목록을 비우려면 **전체 삭제**를 누릅니다.
- **설정**은 패널 상단에서 엽니다. 단축키 칸을 선택하고 새 키 조합을 누른 뒤 저장하면 바로 적용됩니다. 설정 화면에서 현재 단축키를 누르면 화면을 캡처할 수 있습니다.
- 트레이 메뉴에서도 두 기능을 열 수 있습니다. 패널의 상단을 드래그해 이동하고, 닫으면 트레이로 돌아갑니다.

복사가 끝나면 화면 오른쪽 아래에 작은 반투명 미리보기가 약 0.5초 동안 나타납니다. 복사한 이미지는 AI 입력창 등에서 Ctrl+V로 붙여넣습니다. 팝업은 먼저 열고 캡처 단축키를 누르세요. 영역 선택 전에 화면을 확보하므로 이후 닫힌 팝업의 픽셀도 유지됩니다.

최근 캡처는 최대 10장을 메모리에 보관하며 종료하면 비워집니다. 약 64MiB 한도에서 오래된 이미지부터 정리하되, 최신 한 장이 큰 경우 그 이미지는 유지합니다. 기존 설정에 저장된 영역 캡처 단축키는 등록할 수 있을 때 이어받습니다.

## 실행과 빌드

Windows x64. 설치형은 런타임을 설치 시 배치하며 휴대용은 단일 EXE입니다. 구버전이 트레이에서 실행 중이면 먼저 종료하세요.

새 설치 파일을 실행하면 기존 설치 범위와 폴더에서 업데이트됩니다. 설치형은 Windows에 로그인하면 트레이에서 자동으로 시작됩니다. 자동 실행을 끄려면 Windows의 시작 앱 설정을 이용하세요. 모든 사용자용으로 설치했다면 Windows가 관리자 권한을 요청합니다. 단축키 설정은 Windows 사용자별로 유지됩니다. **설정 → 라이선스 고지**에서 배포 구성 요소의 고지문을 열 수 있습니다.

**설정 → 업데이트 확인**에서 GitHub의 최신 안정 버전을 확인할 수 있습니다. 새 버전이 있으면 릴리스 페이지에서 설치 파일을 받을 수 있습니다.

```powershell
python -m pip install -r requirements.txt
python hwp_capture.py
python -m unittest discover -s tests -v
python -m pip install pyinstaller
powershell -ExecutionPolicy Bypass -File build_portable.ps1
& "$env:LOCALAPPDATA\Programs\Inno Setup 6\ISCC.exe" installer.iss
```
