# Serotonin 바로캡처 v1.0.0

광고·계정·서버 없이 Windows PC 안에서 빠르게 캡처하고 편집하는 첫 정식 릴리스입니다.

## 주요 기능

- 영역, 창, 스텝 캡처와 전역 단축키
- 캡처 직후 클립보드 복사, 자동 저장, 미리보기
- 텍스트, 번호, 도형, 펜, 형광펜, 모자이크, 자르기 편집
- 화면 고정, Windows 내장 OCR, 개인정보 자동 가리기
- PNG, JPG, BMP, GIF, WEBP 저장과 목표 용량 맞추기
- GitHub 최신 안정 릴리스 자동·수동 확인

## 업데이트 안내

앱은 시작 후 최신 안정 릴리스를 비동기로 확인하며 새 버전이 있을 때만 알립니다. 변경 사항과 다운로드 페이지를 보여주지만, 사용자의 명시적인 선택 없이 업데이트를 내려받거나 실행하지 않습니다.

이번 버전보다 앞선 설치본에는 업데이트 확인 기능이 없으므로 v1.0.0을 한 번 직접 설치해야 이후 새 버전 알림을 받을 수 있습니다.

## 주의

이 릴리스의 Windows 실행 파일은 코드 서명이 적용되지 않았습니다. 처음 실행할 때 Microsoft Defender SmartScreen 안내가 표시될 수 있습니다.
