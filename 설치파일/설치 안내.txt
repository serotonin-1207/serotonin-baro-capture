Serotonin 바로캡처 (v1.0.0) — 설치 안내
=========================

제작: 이은호 · 문의: serotonin.1207@gmail.com
광고·계정·서버 없이 내 PC 안에서만 동작하는 화면 캡처 도구입니다.


[설치 방법]
1. "Serotonin_BaroCapture_Setup_v1.0.0.exe" 파일을 더블클릭합니다.
2. "설치"를 누르면 끝납니다. 관리자 권한(보안 경고)이 필요 없습니다.
   - 설치하면 자동으로 "Windows 시작 시 자동 실행"이 켜집니다(별도 설정 불필요).
   - 설치 직후 프로그램이 바로 실행되고, 이후 컴퓨터를 켤 때마다 자동 대기합니다.
   - (선택) "바탕화면에 바로가기 만들기"만 체크 여부를 고를 수 있습니다.


[사용 방법]
- 기본 캡처 단축키:  Ctrl + Shift + Z
- 단축키를 누르고 캡처할 영역을 드래그하면
  이미지 파일 저장 + 클립보드 복사가 동시에 됩니다.
- 한글(HWP)·워드 등에서 Ctrl + V 로 바로 붙여넣으면 됩니다.
- 저장 폴더는 기본적으로 "다운로드\캡처" 입니다.
- 편집 창에서 텍스트·번호·도형·펜·형광펜·자(직선)·모자이크 등을 쓸 수 있고,
  Ctrl + Z (이전) / Ctrl + Y (다시) 로 되돌릴 수 있습니다.


[자동 실행]
설치하면 컴퓨터를 켤 때마다 자동으로 트레이(작업표시줄 우측)에서 대기합니다.
프로그램을 따로 실행할 필요 없이 단축키만 누르면 됩니다.
(자동 실행을 끄려면: 프로그램 > 일반 설정 > "Windows 시작 시 자동 실행" 체크 해제)


[삭제 방법]
- Windows 설정 > 앱 > "Serotonin 바로캡처" > 제거
- 또는 시작 메뉴에서 "Serotonin 바로캡처 제거" 실행


[참고]
- 별도의 인터넷 연결이나 파이썬 설치가 필요 없습니다.
- 처음 실행 시 Windows Defender(SmartScreen) 경고가 나올 수 있습니다.
  서명되지 않은 개인 제작 프로그램이라 그렇습니다.
  "추가 정보" > "실행"을 누르면 정상 실행됩니다.
- 단축키 Ctrl+Shift+Z 가 다른 프로그램과 겹치면, 프로그램의
  "단축키 설정"에서 다른 키로 바꿀 수 있습니다.
